# K-FOOD 게임천국 🕹️

K-Food 박람회 PC방 컨셉 부스용 미니게임 모음. **설치 불필요, 인터넷 불필요** — `index.html`을 브라우저로 열면 끝.

## 실행 방법

1. `index.html` 더블클릭 (Chrome/Edge 권장)
2. **F11** 눌러 전체화면
3. 끝. 서버·설치·인터넷 필요 없음.

## 게임 구성

| 게임 | 파일 | 조작 | 점수 방식 |
|---|---|---|---|
| 🏃 네온 러너 | `runner.html` | 스페이스바(점프·2단점프), ↓(숙이기·급강하) | 달린 거리 (끝없음, 점점 빨라짐) |
| 🚀 벡터 스트라이크 | `shooter.html` | 마우스 이동 (공격 자동) | 격추 + 콤보 배율. 15웨이브 최종보스 격파 시 클리어(끝) + 보너스 |

두 게임 모두 게임오버 시 **등급(S/A/B/C/D)이 화면 중앙에 크게 표시**됨 → 직원이 확인 후 포인트 지급.

## 사운드

- BGM과 모든 효과음은 **Web Audio API로 코드에서 실시간 합성** — 외부 음원 파일이 없어 저작권 문제 없음
- 러너: 속도가 붙을수록 BGM 템포도 빨라짐. 점프/2단점프/급강하/숙이기/착지/100점 마일스톤/충돌 효과음
- 슈팅: 일반전·보스전 BGM 2곡. 발사/명중/격추/보스 폭발/피격/아이템/웨이브 알림/보스 경보/미사일 효과음
- 게임오버 시 등급별 다른 징글(S일수록 화려함), 클리어 시 팡파레
- **M 키**: 소리 켜기/끄기 (브라우저 정책상 첫 클릭·키 입력 후부터 소리 재생됨)

## 점수 저장

- 브라우저 `localStorage`에 저장 (해당 PC에서만 유지, 브라우저 꺼도 남음)
- `index.html` 하단 순위표에 TOP 10 표시
- 행사 종료 후: `index.html` 맨 아래 **"기록 전체 초기화 (운영자용)"** 버튼

⚠️ 시크릿 모드로 열면 기록이 저장되지 않음. 일반 창으로 열 것.

## 등급 기준 조정

각 게임 파일 상단의 `CONFIG.grades`에서 기준 점수(`min`) 수정:

```js
grades: [
  { min: 3000, label: 'S', ... },   // 3000점 이상 → S
  { min: 2000, label: 'A', ... },
  ...
]
```

난이도·속도 등도 같은 `CONFIG` 객체에서 조정 가능 (주석 참고).

## 저작권

모든 그래픽은 Canvas 코드로 직접 그린 오리지널 도형이며, 게임 룰도 특정 게임을 복제하지 않은 일반적인 장르 문법(러너/슈팅)만 사용. 외부 라이브러리·이미지·폰트·사운드 없음.
