# K-FOOD 게임천국 🕹️

K-Food 박람회 **PC방 컨셉 부스**용 아케이드 웹앱. 게임에서 점수를 올리면 등급(S~D)이 나오고, 부스 직원이 확인해 음식 포인트로 교환해주는 흐름을 위해 만들었습니다.

## 기술 스택

| | |
|---|---|
| 빌드 | Vite 5 + TypeScript (strict) |
| UI | React 18 + React Router 6 |
| 애니메이션 | Framer Motion 11 (3D 틸트 카드, 페이지 전환, 스태거 리스트) |
| 게임 렌더링 | Canvas 2D — 프레임워크 없는 순수 게임 루프 |
| 사운드 | Web Audio API 실시간 합성 (음원 파일 없음) |
| 배포 | Vercel (`vercel.json` 포함, SPA 리라이트 설정됨) |

## 실행

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm run build      # 타입체크 + 프로덕션 빌드 → dist/
npm run preview    # 빌드 결과 로컬 확인
```

### Vercel 배포

이 저장소를 Vercel에 연결하면 별도 설정 없이 자동 빌드됩니다 (Framework: Vite, Output: `dist`).
CLI로 할 경우:

```bash
npx vercel --prod
```

부스에서는 배포된 URL을 브라우저로 열고 **F11**로 전체화면을 권장합니다.

## 프로젝트 구조

```
src/
├─ main.tsx              라우터 진입점
├─ routes/               Home / RunnerPage / ShooterPage
├─ ui/                   Layout, Background, GameCard, Leaderboard, GameShell
├─ games/
│  ├─ runner.ts          네온 러너 엔진
│  └─ shooter.ts         벡터 스트라이크 엔진
├─ lib/
│  ├─ sound.ts           Web Audio 합성 엔진 (16스텝 시퀀서 + SFX)
│  └─ score.ts           점수·등급 저장소 (localStorage)
└─ styles/global.css     디자인 토큰 + 배경 레이어
```

게임 엔진은 React와 분리된 순수 TS 모듈입니다. `createRunner(canvas)` / `createShooter(canvas)`는 정리 함수를 반환하고, `GameShell`이 언마운트 시 호출해 이벤트 리스너·RAF·BGM을 모두 해제합니다.

## 게임

### 🏃 네온 러너 (`/runner`)
장애물이 개별이 아니라 **동작 콤보 패턴 단위**로 나오는 리듬형 러너.

- **조작**: `SPACE` 점프 / 공중에서 한 번 더 = 2단 점프, `↓` 숙이기 / 공중에서 = 급강하
- **장애물**: 블록(점프), 높은 벽(2단 점프), 드론(숙이기), 높은 드론(페이크), 낮은 천장(구간 내내 숙이기)
- 속도 3티어로 패턴 풀이 어려워지고, 간격은 속도에 비례 확대되어 리듬 간격(0.3~0.45초)이 유지됨
- BGM 템포가 주행 속도에 연동됨

### 🚀 벡터 스트라이크 (`/shooter`)
**15웨이브 + 최종보스**로 끝이 있는 종스크롤 슈팅. 수학 공식으로 적 패턴을 구성했습니다.

| 패턴 | 공식 |
|---|---|
| 사인파 편대 | `x(t) = x₀ + A·sin(ωt + φ)` — 위상차로 편대 지그재그 |
| 나선 진입 | 극좌표 `(r·cosθ, r·sinθ)`, 반경 지수 수렴 + 타원 압축 |
| 조준탄 / 돌진 | 벡터 정규화 `(P−E)/‖P−E‖` |
| 링 탄막 | 원 n등분 `vᵢ = spd·(cos 2πi/n, sin 2πi/n)`, 매 발사 반 칸 회전 |
| 유도 미사일 | 각도차 `[−π,π]` 정규화 후 각속도 제한 조향 |
| 최종보스 이동 | 리사주 곡선 `x=A·sin(at)`, `y=B·sin(bt+δ)` |

- **조작**: 마우스 이동(지수 보간 추적) 또는 방향키, 사격 자동
- **무기 강화**: `P` 아이템으로 Lv.1(단발) → Lv.5(5방향 고속연사). **피격 시 1단계 하락**
- **최종보스**: HP 3단계 페이즈 — 회전 링 → 양방향 나선 스트림 → 이중 링 + 유도미사일
- 격파 시 **MISSION CLEAR** + 보너스 5,000점 + 남은 목숨당 2,000점

## 사운드

BGM·효과음 전부 **Web Audio API로 코드에서 실시간 합성** — 외부 음원 파일이 없어 저작권 문제가 없습니다.

- 16스텝 시퀀서(킥/하이햇/베이스/리드)로 BGM 생성, 룩어헤드 스케줄링으로 타이밍 안정
- 슈팅은 일반전·보스전 BGM 2곡이 상황에 따라 전환
- 상황별 효과음: 점프/2단점프/급강하/착지/마일스톤/충돌, 발사/명중/격추/보스폭발/피격/아이템/웨이브/보스경보
- 게임오버 시 **등급별 다른 징글**, 클리어 시 팡파레
- `M` 키로 음소거. 브라우저 정책상 첫 클릭·키 입력 이후부터 소리가 납니다

## 부스 운영

- **등급 표시**: 게임 종료 시 S/A/B/C/D가 화면 중앙에 대형으로 표시 (0.8초 잠금 후 재시작 가능 — 실수로 넘어가는 것 방지)
- **점수 저장**: 브라우저 `localStorage` (해당 PC에서만 유지, 서버·DB 불필요). 홈 화면에 TOP 10 표시
- **행사 종료 후**: 홈 화면 하단 "기록 전체 초기화 (운영자용)" 버튼
- ⚠️ 시크릿 모드에서는 기록이 저장되지 않습니다. 일반 창으로 여세요

### 난이도·등급 조정

각 엔진 파일 상단의 `CONFIG` 객체만 수정하면 됩니다.

```ts
// src/games/shooter.ts
const CONFIG = {
  grades: [{ min: 30000, label: 'S', ... }, ...],  // 등급 기준 점수
  lives: 3,
  finalWave: 15,        // 최종보스가 나오는 웨이브
  clearBonus: 5000,
  ...
};
```

리허설로 실제 점수 분포를 본 뒤 `grades`의 `min` 값을 조정하는 것을 권장합니다.

## 저작권

모든 그래픽은 Canvas/SVG 코드로 직접 그린 오리지널이고, 사운드는 실시간 합성이며, 게임 룰도 특정 작품을 복제하지 않은 일반 장르 문법(러너/종스크롤 슈팅)만 사용합니다. 폰트는 Google Fonts의 오픈 라이선스 서체(Orbitron, Noto Sans KR)입니다.
